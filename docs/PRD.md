# 羊毛衫档口小程序 — 产品需求（PRD）

> 与代码对齐：下列能力均为**已落地验收标准**（含商品分组、访问日志、昵称头像、订阅申请、联系二维码、素材多缩略拼贴）。宣传视频生成仍可占位提示，但列表/入口已统一。

## 0. 产品定位与角色

**一句话**：档口业主用小程序管货、做宣传素材、把商品卡片分享给客户；客户无登录页，点开分享即看详情并可询价。

| 角色 | 入口 | 能力摘要 |
|------|------|----------|
| owner / staff | 首页显式「微信登录」→ Tab：商品 / 客户 / 任务 | 发品、编辑、分享、宣传素材、任务、客户等级 |
| customer | 仅分享落地 `pages/share/landing/landing` 静默鉴权 | 看详情（策略允许时）、询价、按开关存图；无管理 Tab |

同一 AppID 双端；首个真实微信登录且走管理端入口、且档口尚无真实业主时，自动绑定为 owner。

## 1. 发品：异步草稿

| 项 | 内容 |
|----|------|
| **目标** | 选图后尽快进入可编辑草稿，识图/选封面在后台跑，用户不长时间同步等待 |
| **角色** | owner / staff |
| **现状** | 已落地：`POST /api/products/publish/async`（或 upload + `:batchId/enqueue`）→ 立即返回 `jobId` + `productId`，跳转编辑页；handler `publish_product` 后台补全 |
| **验收** | ① 选图后数秒内出现草稿商品（可编辑）② 任务中心可见「选图发品 / 识别中·草稿」类标题 ③ 完成后封面与字段补全可刷新看到 ④ 失败可在任务中心重试 |

可选旧路径：`upload` → `analyze` → `confirm`（人工确认），主按钮已走异步。

## 2. 手工大文本（笔记粘贴解析）

| 项 | 内容 |
|----|------|
| **目标** | 从微信笔记复制大段文字，一键解析款号/名称/成分/颜色等到表单 |
| **角色** | owner / staff |
| **现状** | 已落地：编辑页大文本框 + `POST /api/products/parse-note` |
| **验收** | 粘贴典型笔记文本 → 点解析 → 款号/名称/材质/颜色 SKU 草案有合理填充；可再手工改 |

## 3. 图序与「禁下图」（封面策略）

| 项 | 内容 |
|----|------|
| **目标** | 商品图有明确顺序（`coverMediaIds`）；自动选封面时**禁止**把尺码表/质检报告/吊牌文字图等当作封面主图；文字类沉底 |
| **角色** | 系统（vision）+ staff 可手工调序 |
| **现状** | 已落地：`vision/cover-select.ts` 启发式 + 多模态；编辑页调序 PATCH `coverMediaIds` |
| **验收** | ① 混入尺码表/质检图时封面不为该类 ② 调序后详情/列表展示序一致 ③ 吊牌可用于 OCR，但不作默认封面首选 |

## 4. SKU：一色一行 + 复制价

| 项 | 内容 |
|----|------|
| **目标** | SKU UI 一色一行：颜色、价格、删除；无库存列；可一键把价格复制到全部行 |
| **角色** | owner / staff |
| **现状** | 已落地：`components/sku-list`「一键复制价格」 |
| **验收** | 填第一行（或任一非空）价格 → 复制 → 全部行同价；发品草案与编辑页行为一致 |

说明：尺码写入描述说明，不拆独立 size SKU（发品确认「一色一 SKU，size=null」）。

## 6. 宣传素材：多组、合并入口、缩略列表

| 项 | 内容 |
|----|------|
| **目标** | 一商品多组 `promo_set`；详情缩略入口；统一素材页列表（图组；视频组占位） |
| **角色** | owner / staff |
| **现状** | 已落地：表 `promo_sets`；详情缩略；`promo-gallery` 列表/展开/重生成/删除；`promo` 向导新建 |
| **验收** | ① 多次生成产生多组 ② 详情多缩略拼贴（2～4）/视频首帧 ③「宣传素材」进合并列表 ④ 文案复制；勾选存相册 ⑤ 同模板进行中不双开；任务/列表不重复显示「多色」 ⑥ 多色每色一张上身图（非拼贴） |
| **备注** | 宣传**视频**生成引擎可后续迭代；列表已支持视频组 UI（首帧封面/类型标） |
| **风格样例** | 已落地：参考图卡片内可选上传 0～4 张 + 强弱弱/中/强；`styleRefObjectKeys` / `styleStrength`；设计见 [PROMO_REF_IMAGE_DESIGN.md](./PROMO_REF_IMAGE_DESIGN.md) |

## 8. 分享访问；昵称头像；订阅提醒

### 8.1 分享访问（已落地）

| 项 | 内容 |
|----|------|
| **目标** | 员工创建分享 → 客户落地静默 login → open → 首访绑定 → 详情 |
| **验收** | 限制分享：前 N 位打开链接的客户可看，其后拒绝；公开分享：不限人数 |

### 8.2 昵称 / 头像（已落地）

| 项 | 内容 |
|----|------|
| **目标** | 客户访问时采集展示用昵称、头像，写入 `customer_profiles` |
| **现状** | `GET/PATCH /api/auth/me`；详情页引导；设置页 `chooseAvatar` + 昵称；客户列表展示 |
| **验收** | 授权后客户列表见昵称头像；拒绝/跳过不阻断看商品 |

### 8.3 订阅消息提醒（已落地）

| 项 | 内容 |
|----|------|
| **目标** | 关键节点（发品/宣传提交前）申请订阅消息授权 |
| **现状** | 发品/宣传提交前 `wx.requestSubscribeMessage`（模板 ID 可配 `globalData.subscribeTmplIds` / 本地缓存）；后端 `WechatService.sendSubscribeMessage` 已具备 |
| **验收** | 未配置模板 ID 时静默跳过；配置后弹出订阅面板；拒绝不影响主流程 |

|----|------|
| **目标** | 员工自行新建/改名/设本季/删除分组，不限本季+过季两档 |
| **角色** | owner / staff |
