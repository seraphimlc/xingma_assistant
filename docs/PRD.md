# 星马档口助手 — 产品需求（PRD）

> 与代码对齐：下列能力均为**已落地验收标准**。密钥不入仓。

## 0. 产品定位与角色

**一句话**：档口业主用小程序管货、做宣传图/短视频素材、把商品卡片分享给客户；客户无登录页，点开分享即看详情并可询价、逛公开目录。

| 角色 | 入口 | 能力摘要 |
|------|------|----------|
| owner / staff | 首页「微信登录」→ Tab：商品 / 客户 / 任务 / 设置 | 发品、编辑、分享、宣传素材（图+视频）、任务、客户、邀请同事 |
| customer | 仅分享落地 `pages/share/landing` 静默鉴权 | 看详情 `product/view`、询价、公开目录 `product/catalog`、按开关存图；无管理 Tab |

同一 AppID 双端；首个真实微信登录且走管理端入口、且档口尚无真实业主时，自动绑定为 owner。

---

## 1. 发品：异步草稿

| 项 | 内容 |
|----|------|
| **目标** | 选图后尽快进入可编辑草稿，识图/选封面在后台跑 |
| **现状** | `POST /api/products/publish/async` → 立即返回 `jobId` + `productId`，跳转编辑页；handler `publish_product` 后台补全；**识别成功后默认 `on_sale`**，标题弱 / `needReview` 只打标不自动下架（显式 `off_sale`/`draft` 除外；款号冲突仍强制下架） |
| **验收** | 数秒内出现草稿；识别成功后商品在售；弱标题仍在售且带 needReview；任务中心可见友好标题；失败可重试 |

---

## 2. 手工大文本（笔记粘贴解析）

编辑页大文本 + `POST /api/products/parse-note`；解析款号/名称/材质/颜色草案后可再改。

---

## 3. 图序与「禁下图」

`coverMediaIds` 有序；自动封面禁止尺码表/质检/吊牌文字图；编辑页可调序。

---

## 4. SKU：一色一行 + 复制价

`components/sku-list` 一色一行、无库存列、「一键复制价格」；尺码写入描述（size=null）。

---

## 5. 管理员 / 客户两套详情 + 公开目录

| 项 | 内容 |
|----|------|
| 员工 | `pages/product/detail`：分享、素材、编辑 |
| 客户 | `pages/product/view`：无管理控件；首次可软提示「完善资料」（头像+昵称+手机，可跳过） |
| 目录 | 客户页「房子 / 更多」进 `pages/product/catalog`（公开目录），**绝不**进员工 list / 管理 Tab |

---

## 6. 宣传素材：图组 + 视频组

| 项 | 内容 |
|----|------|
| **目标** | 一商品多组 `promo_set`；详情缩略；gallery 列表/重生成/删组/文案复制/存相册 |
| **图** | 多模板（细节/平铺/模特场景/多色/小红书封面/风格参考）；可走自建 IMAGE_GEN 或外部穿搭 Agent（`OUTFIT_ENGINE`） |
| **视频** | **已落地**：场景模板 + 可编辑分镜 → `promo_video`；默认 LKB `sinan-video-generator`（`rsync`+poll）；**一律 `generateAudio=true`**；上游 SUCCEEDED 直链入库；自有上传亦用 xy-tradex 桶；小程序播放上游/自有绝对 URL（downloadFile 白名单已含该桶） |
| **验收** | ① 多次生成多组 ② 视频可在 gallery/详情播放 ③ 同模板进行中不双开 ④ 多色每色一张（非拼贴） |

设计细节：[PROMO_REF_IMAGE_DESIGN.md](./PROMO_REF_IMAGE_DESIGN.md)、[PROMO_EXTERNAL_OUTFIT.md](./PROMO_EXTERNAL_OUTFIT.md)、[生图模板设计.md](./生图模板设计.md)、TECH §4.2 / §6。

## 7. 任务友好 UI

Tab「任务」按业主可读标题（`job-display-title`）；宣传任务按 `promo_set` 呈现；失败可重试；框架调试 job 不打扰业主。

---

## 8. 分享访问；完善资料；订阅

### 8.1 分享

限制分享（`designated_only`，前 N 位，默认 `SHARE_LIMIT_SLOTS=5`）/ 公开分享（`open`）。列表可用「限量转发」文案。客户 landing → open → `product/view`。

### 8.2 完善资料（已落地）

首次客户打开软弹完善头像+昵称+手机（可跳过，不挡看货）；`GET/PATCH /api/auth/me`；设置页亦可改。

### 8.3 订阅消息

发品/宣传提交前可申请订阅（模板 ID 可配）；未配置则跳过。

---

## 9. OSS 与外部直链

- 自有上传：`OSS_PROVIDER=aliyun`，当前公开读。
- **LKB 视频 / 外部穿搭结果**：上游 http(s) 直链写入 `promo_sets.images[].url|externalUrl`（及 media `provider=external`），**默认不下载、不转存自有 OSS**。
- 视频播放：API 返回绝对 URL（xy-tradex 直链）；`/api/media/external-play` 仅应急保留，默认不改写。

## 16. 询价处理流（已落地）

| 项 | 内容 |
|----|------|
| 客户 | 商品页提交询价（可留手机/姓名） |
| 员工 | 列表红点；详情「我来沟通」`POST …/claim` → `in_progress`；「已处理」`POST …/handled`（可写说明） |
| 验收 | 已处理后红点清除；处理人昵称可见；他人已认领不可抢（除非规则允许） |

迁移：`012`/`013`/`017`。

---

## 17. 员工邀请（已落地）

| 项 | 内容 |
|----|------|
| 入口 | 设置 →「员工邀请」：生成邀请、微信转发、邀请记录 |
| 兑换 | 扫码/卡片 → `pages/invite/accept`（或首页带码跳转）→ login+`inviteCode` |
| 记录行 | **单行不换行**：码 + 状态/已用；右侧「邀请」「撤销」挨近；无「员工」前缀、无「复制」、无「有效」赘词占位（非 active 才显示中文状态） |
| 注意 | 员工邀请 ≠ 客户商品分享 |
