# 生产部署说明（xingma.visitworld.me）

| 项 | 值 |
|----|----|
| 域名 | `xingma.visitworld.me`（假设已解析到服务器公网 IP） |
| API 基址 | `https://xingma.visitworld.me`，接口路径 `/api/*` |
| 小程序 AppID | `wx394d23ea099d8a01` |
| AppSecret | **不入仓库**，仅放服务器 `backend/.env` 的 `WECHAT_APP_SECRET`（或 `tenants.wx_app_secret`） |

## 1. 服务器准备

- Node.js 20+、MySQL 8（或 MariaDB 10.6+）、Nginx、certbot
- 代码放到 `/srv/wool-stall-miniapp`（主机 `xingma.visitworld.me` / `8.216.43.224`，ssh 别名常为 `store-old`；同机还有其它 pm2 应用）

## 2. MySQL 建库与迁移

```bash
mysql -uroot -p <<'SQL'
CREATE DATABASE wool_stall DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'wool'@'127.0.0.1' IDENTIFIED BY '<强密码>';
GRANT ALL ON wool_stall.* TO 'wool'@'127.0.0.1';
SQL
cd /srv/wool-stall-miniapp/backend
# 按序执行全部迁移 001…019（部分幂等；已执行过的 Duplicate 可忽略）
for f in migrations/*.sql; do
  echo "== $f =="
  mysql -h127.0.0.1 -uwool -p wool_stall < "$f" || true
done
```

002、003 可重复执行。003 写入默认租户（`tenant_dev_001` ↔ `wx394d23ea099d8a01`）和默认客户/商品等级，`wx_app_secret` 为 NULL。
可选：把 secret 存进租户表（而非 .env）：在服务器上执行
`UPDATE tenants SET wx_app_secret='<AppSecret>' WHERE wx_app_id='wx394d23ea099d8a01';`

## 3. 后端配置与启动

```bash
cd backend
cp .env.example .env
# 编辑 .env：
#   NODE_ENV=production
#   APP_BASE_URL=https://xingma.visitworld.me
#   WECHAT_APP_ID=wx394d23ea099d8a01
#   WECHAT_APP_SECRET=<在 mp 后台「开发管理-开发设置」获取>
#   DEV_FAKE_LOGIN=false          ← 生产必须 false
#   DB_ENABLED=true  DB_HOST/DB_USER/DB_PASSWORD/DB_NAME
#   JWT_SECRET=$(openssl rand -hex 32)
npm ci && npm run build
# 进程守护（二选一）
npx pm2 start dist/main.js --name wool-api && npx pm2 save
```

密钥：`WECHAT_APP_SECRET`、`JWT_SECRET`、`OSS_*`、`IMAGE_GEN_*`、以及宣传视频/穿搭 Agent（`VIDEO_LKB_*` / `OUTFIT_AGENT_*`，或 `backend/.secrets/*.key`）**只放服务器**，勿提交仓库。更新后**仅** `pm2 restart wool-api`。


启动日志会打印 `DB_ENABLED`、`DEV_FAKE_LOGIN`、`WECHAT_APP_SECRET=已配置/未配置`（不打印值）。
未配置 secret 时 `/api/auth/login` 返回 503 并提示配置位置。

## 4. Nginx 反代 + HTTPS

```nginx
server {
    listen 80;
    server_name xingma.visitworld.me;
    location /.well-known/acme-challenge/ { root /var/www/html; }
    location / { return 301 https://$host$request_uri; }
}

server {
    listen 443 ssl http2;
    server_name xingma.visitworld.me;

    ssl_certificate     /etc/letsencrypt/live/xingma.visitworld.me/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/xingma.visitworld.me/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;   # 微信要求 TLS 1.2+

    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;
        proxy_read_timeout 30s;
    }
}
```

证书：`sudo certbot --nginx -d xingma.visitworld.me`（或用云厂商证书）。
自测：`curl https://xingma.visitworld.me/api/health`。Node 只监听本机，3000 端口不对公网开放。

## 5. 小程序后台配置（mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名）

| 类型 | 值 |
|------|----|
| request 合法域名 | `https://xingma.visitworld.me` |
| uploadFile 合法域名 | 若图片直传 OSS/COS：填存储桶域名，如 `https://<bucket>.oss-cn-xxx.aliyuncs.com`；若经后端上传则填 `https://xingma.visitworld.me` |
| downloadFile 合法域名 | **必须配置**：`https://xy-tradex.oss-cn-shenzhen.aliyuncs.com`（自有 OSS + LKB 宣传视频直链）；可选 `https://xingma.visitworld.me`（本站下载 / 应急 external-play） |

`<image>` 显示网络图片一般不需要 downloadFile；**`<video src>` 网络地址与 `wx.downloadFile` 都要求域名在 downloadFile 列表**。已把 `xy-tradex.oss-cn-shenzhen.aliyuncs.com` 加入白名单，播放走绝对 URL，**不**再默认改写为 `/api/media/external-play`。域名必须已备案、HTTPS。

Nginx：`location /api/` 的 `proxy_read_timeout` 建议 ≥ 120s（长请求/应急中转）。
